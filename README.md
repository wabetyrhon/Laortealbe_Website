## Overview
This is Laortealbe Meatshop a online website food shop where you can order different meat products.

## How to run or test
### Locally
1. git clone https://github.com/wabetyrhon/Laortealbe_Website
2. cd Laortealbe_Website
3. python -m pip install -r requirements.txt
4. create/configure a .env file (see .env.example)
5. python -m flask run

### Deployment URL
- "https://laortealbe.onrender.com/"

## Description
This build is made for a feasibility business which we have conjured up for this project. It is a virtual website-based market for a usual meat store that offers different types of meat, where customers can order the products they want.
The customer process starts when the customer visits the virtual meat store website and views the available meat products. The customer selects the product they want to order, chooses the quantity, and provides the required information for the order.
After placing the order, the system generates an RTN (Reservation Tracking Number) that serves as the customer's order confirmation. The customer can then use the RTN when claiming or picking up the products they ordered from the meat store.

This build also has an admin feature where administrators can see the history of reservations made along with their respective RTN for confirmation of orders. Add a product that they want to put in the list of available products.
View a built-in overview for a fast checking of the current state of the website.
